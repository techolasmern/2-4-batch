# OTP API - ENVs

```bash
port = 8080 # Port number for the server to run on

gmail_user = your_gmail_user@gmail.com # Your Gmail username
gmail_pass = your_gmail_password # Your Gmail App Password (Don't use your regular password !)

database_string = mongodb://localhost:27017 # MongoDB connection string
database_name = otp_sample_db # MongoDB database name
```
